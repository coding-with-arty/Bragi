# 🎸 FretTrain v1.0.1 — Cross-Platform Release

Welcome to **FretTrain v1.0.1**! This update introduces automated multi-platform builds, enhanced execution stability across operating systems, and streamlined standalone installers for Windows, macOS, and Linux.

---

### ✨ Highlights & Improvements

- **Cross-Platform Distribution:** Native standalone packages built automatically for Windows (x64), macOS, and Linux (x86_64).
- **Packaging & Performance:** Refined PyInstaller bundle configurations for faster startup times and reduced binary overhead.
- **UI & Core Fixes:** Resolved session state synchronization bugs and improved layout scaling on high-DPI displays.

---

### How to Download and Run FretTrain

1. **Download the Application Zip:** 1-2 minutes.
   Scroll down to the **Assets** section at the bottom of this release page and click on **`FretTrain-v1.0.2-windows-x64.zip`** to save it to your computer.

_Verification:_ Open your **Downloads** folder and confirm you see the downloaded `.zip` file.

2. **Extract the Zip Archive:** 1 minute.
   Right-click the downloaded `.zip` file and select **Extract All...**, then click **Extract**.

_Verification:_ Open the newly extracted folder and confirm you see `main.exe` sitting right next to the `_internal` folder.

3. **Launch the Application:** 30 seconds.
   Double-click **`main.exe`** to open FretTrain.

_(If Windows displays a **"Windows protected your PC"** SmartScreen popup: Click **More info**, then click **Run anyway**)._

_Verification:_ Confirm that the FretTrain application window opens on your screen with the background image and controls loaded.
