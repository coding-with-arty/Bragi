# 🎸 FretTrain v1.0.1 — Cross-Platform Release

Welcome to **FretTrain v1.0.1**! This update introduces automated multi-platform builds, enhanced execution stability across operating systems, and streamlined standalone installers for Windows, macOS, and Linux.

---

### ✨ Highlights & Improvements
* **Cross-Platform Distribution:** Native standalone packages built automatically for Windows (x64), macOS, and Linux (x86_64).
* **Packaging & Performance:** Refined PyInstaller bundle configurations for faster startup times and reduced binary overhead.
* **UI & Core Fixes:** Resolved session state synchronization bugs and improved layout scaling on high-DPI displays.

---

### 📦 Downloads & Platform Binaries

Download the appropriate package for your operating system from the **Assets** section below:

| Operating System | Package Name | Installation Guide |
| :--- | :--- | :--- |
| **Windows (64-bit)** | `FretTrain-v1.0.0-windows-x64.zip` | Extract `.zip` and double-click `FretTrain.exe` |
| **macOS (Intel / Apple Silicon)** | `FretTrain-v1.0.0-macOS.dmg` | Open `.dmg` and drag `FretTrain` to Applications |
| **Linux (x86_64)** | `FretTrain-v1.0.0-linux-x86_64.tar.gz` | Extract `.tar.gz` and execute `./FretTrain` |

---

### 🚀 Quick Start & Security Notes

#### 🍏 macOS Gatekeeper Setup
If macOS blocks execution with an "Unidentified Developer" prompt:
1. Locate `FretTrain.app` in your Applications folder.
2. **Right-click (or Control-click)** the icon and select **Open**.
3. Click **Open** in the security pop-up to save the execution permission.

#### 🪟 Windows SmartScreen Setup
If Windows Defender SmartScreen presents a warning dialog:
1. Click **More info**.
2. Select **Run anyway**.
